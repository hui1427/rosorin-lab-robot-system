# STM 源码模块解析

现有 STM32 原始资料是 HEX 固件镜像，**没有 STM32 固件工程源码**。本目录按功能整理的是固件文件以及主控端与控制板通信的代码，不能据此判断固件内部实现。

| 模块 | 作用与代码 |
| --- | --- |
| 固件镜像 | [STM32固件镜像](源码/STM32固件镜像/)：提供控制板固件文件。 |
| 通信节点与协议 | [控制板节点与串口协议](源码/控制板节点与串口协议/)：ROS 节点和 Python SDK，包含串口收发、报文及控制接口。 |
| 消息与服务 | [控制板消息与服务](源码/控制板消息与服务/)：电机、舵机、蜂鸣器等消息和服务定义。 |
| 启动与设备规则 | [控制板启动与设备规则](源码/控制板启动与设备规则/)：启动文件及串口设备规则。 |
| 包配置 | [包配置与其他待核实](源码/包配置与其他待核实/)：包声明、构建配置及测试文件。 |

这些文件为此前分类副本，未进行编译或实机测试。
