# ROSOrin 机器人代码库

按用途分成三档：先看商家资料，再分别查看 STM 和 ROS 模块。

1. [商家原始代码](01_商家原始代码/)：分为 [STM](01_商家原始代码/1_STM/) 和 [ROS](01_商家原始代码/2_ROS/)。
2. [STM 的源码模块解析](02_STM源码模块解析/)：固件镜像、控制板通信节点、消息接口和启动规则。
3. [ROS 的源码模块解析](03_ROS源码模块解析/)：按底盘、机械臂、传感器、视觉、导航、AI 等功能分类，模块内可直接查看代码。

**STM 资料边界：** 目前商家 STM 目录中只有固件镜像，未取得 STM32 固件工程源码。STM 模块解析中的 Python 和 ROS 接口是主控端与控制板通信的代码，不等同于 STM32 固件内部源码。

**ROS 资料边界：** 本次附件的同名文件按已有清单和附件顺序恢复；一个配置中的非空密钥已清空，两处 FastSAM 模型未上传。代码尚未编译或实机验证。详见各目录说明。
