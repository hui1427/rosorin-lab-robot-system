# ROS 源码模块解析

以下目录包含按完整功能包整理的实际代码。包内部文件结构保留，分类用于浏览；不同功能之间可能通过 ROS 消息、服务、话题或启动文件关联。

| 模块 | 内容 |
| --- | --- |
| [00 主控与系统架构](源码/00_主控与系统架构/) | 系统启动、通用消息与服务接口。 |
| [01 底盘与标定](源码/01_底盘与标定/) | 底盘控制、里程计及标定。 |
| [02 STM32与硬件通信](源码/02_STM32与硬件通信/) | 控制板通信节点和消息接口。 |
| [03 机械臂与舵机](源码/03_机械臂与舵机/) | 运动学、舵机控制与对应接口。 |
| [04 传感器与遥控](源码/04_传感器与遥控/) | 相机、雷达、IMU、手柄等入口。 |
| [05 基础应用与视觉](源码/05_基础应用与视觉/) | 基础应用与视觉示例。 |
| [06 建图与导航](源码/06_建图与导航/) | SLAM 和导航功能包。 |
| [07 AI与语音](源码/07_AI与语音/) | 大模型服务、示例及语音接口。 |
| [08 多机器人协同](源码/08_多机器人协同/) | 多机器人导航与协同代码。 |
| [09 机器人模型与仿真](源码/09_机器人模型与仿真/) | 机器人描述文件、模型和可视化配置。 |
| [10 公共工具](源码/10_公共工具/) | SDK 和基础工具。 |
| [11 实验与二次开发](源码/11_实验与二次开发/) | 实验、视觉和机械臂示例。 |
| [12 综合场景集成](源码/12_综合场景集成/) | 机器人场景任务及控制集成。 |

本目录为分类副本，保留 COLCON_IGNORE，避免构建时与原功能包重复发现。附件目录通过历史清单与编号恢复，同名文件的原路径尚未逐文件核对；一个配置已去除非空密钥。两处 FastSAM 大模型缺失，相关功能不能视为完整可运行。未进行编译或实机测试。
